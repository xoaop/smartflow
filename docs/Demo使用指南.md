# 可运行Demo使用指南

## 一、Demo概述
本Demo是基于飞书生态的智能团队效能周报自动生成系统，实现了"数据采集-内容生成-主动推送"的全自动化流程，支持两种主动触发方式。

## 二、环境要求
- Node.js >= 20.0.0
- 飞书企业自建应用（已申请相关权限）
- 服务器公网IP（用于Webhook回调）

## 三、快速启动
### 3.1 安装依赖
```bash
# 克隆项目
git clone <仓库地址>
cd smartflow

# 安装依赖
npm install
npm run build
```

### 3.2 配置文件
```bash
# 复制配置模板
cp config/config.example.yaml config/config.yaml
cp config/team-config.example.yaml config/teams/dev.yaml
```

编辑配置文件，填写以下信息：
1. `config.yaml`：配置默认团队ID
2. `config/teams/dev.yaml`：配置飞书应用凭证、数据源ID、推送渠道等

### 3.3 启动服务
```bash
# 启动Webhook服务
node smartflow-server.js
```

服务启动后会监听3000端口，输出类似信息：
```
🚀 SmartFlow服务启动成功，监听端口 3000 (所有IPv4地址)
📝 请在飞书开放平台配置事件回调地址为：http://<公网IP>:3000/feishu/webhook
🔧 确保服务器安全组开放了3000端口的入站访问
```

## 四、飞书开放平台配置
### 4.1 事件订阅配置
1. 登录飞书开放平台，进入自建应用
2. 进入「事件订阅」页面，配置请求地址：`http://<公网IP>:3000/feishu/webhook`
3. 点击「验证」，确认回调地址可以正常访问
4. 订阅事件：添加「消息与群组」→「接收消息v2.0（`im.message.receive_v1`）」事件

### 4.2 权限申请
申请以下权限并发布版本：
- `im:message`：发送与接收消息
- `drive:document`：读取文档
- `task:task`：读取任务
- `calendar:calendar`：读取日历
- `contact:user`：读取用户信息

### 4.3 机器人入群
将应用机器人添加到需要接收周报的飞书群中。

## 五、主动触发方式
### 5.1 事件驱动触发（即时响应）
在飞书群中@机器人，发送相关关键词即可主动触发周报生成：

```
@SmartFlow机器人 生成上周周报  # 生成上周一到周日的周报
@SmartFlow机器人 生成本周周报  # 生成本周一到现在的周报
@SmartFlow机器人 生成上月月报  # 生成上个月的月报
@SmartFlow机器人 帮助          # 查看使用说明
@SmartFlow机器人 状态          # 检查服务运行状态
@SmartFlow机器人 测试          # 生成测试样例周报
```

**响应效果**：
1. 首先收到「正在生成周报」的加载卡片
2. 然后收到「数据采集完成」的统计卡片
3. 最后收到完整的交互式周报卡片，包含：
   - 数据统计面板（文档、任务、会议、消息、风险数量）
   - 本周整体概览
   - 重点工作列表（带原文链接）
   - 项目进展（带进度条）
   - 待跟进事项
   - 风险预警（按优先级排序）
   - 下周计划
   - 交互按钮（查看全部、创建任务、配置）

### 5.2 定时推送触发（周期性）
系统支持配置Cron表达式定时自动生成并推送周报：

在团队配置文件中设置：
```yaml
push:
  enabled: true
  cronExpression: "0 18 * * 5"  # 每周五18:00自动推送
  channels:
    - type: "group"
      id: "oc_xxxxxxxxxxxxxx"  # 要推送的群聊ID
```

配置后系统会在指定时间自动采集一周数据，生成周报并推送到指定群聊，无需人工干预。

## 六、效果演示
### 6.1 卡片样式展示
周报采用飞书交互式卡片格式，信息密度高，交互友好：
- 顶部统计面板直观展示本周工作量化数据
- 重点工作每项都带原文跳转链接，支持溯源
- 项目进展用进度条可视化展示完成率
- 风险预警按高、中、低优先级区分展示
- 底部支持快速跳转和操作按钮

### 6.2 完整流程演示
1. 每周五18:00，系统自动采集本周所有数据源数据
2. 调用大模型提炼生成结构化周报内容
3. 自动推送到团队群聊
4. 团队成员点击卡片链接可查看详情
5. 待跟进事项可直接跳转创建飞书任务

## 七、核心技术特点
1. **多租户原生支持**：一套系统可同时服务多个团队，数据完全隔离
2. **容错设计**：单个数据源失败不影响整体流程，API调用自动重试
3. **幻觉抑制**：所有生成内容都关联原始数据来源，避免大模型幻觉
4. **配置驱动**：所有业务逻辑通过YAML配置控制，无需修改代码即可适配不同团队
