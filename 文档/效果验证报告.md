**授权体验问题记录：**
- 第 1 次触发：日历 API 返回 `awaiting_authorization`
- 第 2 次：撤销授权 + 批量重新授权

- 教训：单独权限授权不足，需要一次性批量授权

### 4.2 架构验证结论

SmartFlow 的三层分离架构在妙搭 Agent 环境下验证通过：

```
数据采集层（Agent 工具）  ✅
        ↓
LLM 生成层（Agent 推理） ✅
        ↓
卡片构建层（SmartFlow）  ✅  ← 通过 exec 调用
        ↓
飞书推送层（Agent 工具） ✅
```

**关键发现：** SmartFlow 的 `FeishuCardBuilder` 可以完全独立于 OpenClaw Agent 运行时通过 `node` 直接调用，证明模块解耦设计有效。
